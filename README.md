# 🥖 БАТОН СУДЬБЫ

Мемная RPG на 30–45 минут. Тёмный Менеджер украл священный Батон Судьбы, и только ты
(и, возможно, Гусь) можешь вернуть его королевству.

Один файл-игра без установки, регистрации и внешних библиотек. Работает офлайн,
сохраняется в браузере, играется мышкой или с телефона.

## Как запустить

Самый простой способ — открыть `index.html` двойным щелчком.

Если браузер капризничает с сохранениями на `file://`, запустите локальный сервер:

```bash
python -m http.server 8777
```

и зайдите на <http://127.0.0.1:8777/>.

## Управление

| Действие | Клавиша |
| --- | --- |
| Атака / скилл / предмет / мем / блок | `1`–`6` |
| Классовая способность | `7` |
| Позвать гуся | `G` |
| Удар по таймингу | `Пробел` или `Enter` |
| Сумка | `I` |
| Звук | `M` |
| Помощь | `?` |

На телефоне всё делается тапами: кнопки большие, шкала тайминга тоже.

## Что внутри

- 4 класса со своими навыками: Воин-нытик, Маг-задрот, Плут-курьер, Бард-блогер.
- У каждого класса своя боевая шкала: Обида (воин), Вкладки (маг), Заказ (плут), Подписчики (бард).
- Враги реагируют на класс героя: у курьера — доставка, у мага — документация, у барда — подписчики, у воина — усталость.
- Пошаговые бои с тайминг-ударом: попади в золотую зону — получишь крит.
- В окне победы — журнал боя: можно прочитать весь ход и последние слова врага до прокачки.
- 10 противников, включая Тимлида-Оборотня и финального Тёмного Менеджера с двумя фазами.
- Два новых региона: Министерство Понедельников и Фудкорт Хаоса.
- Ещё 4 боя: Секретарь-Цербер, Инфоцыган, Батон-Двойник и Алгоритм с механикой охватов.
- Гусь-компаньон: 3 способности, уважение 0–5 и 25% шанс, что он скажет «ну это другое».
- Шаурмичная: магазин за лайки — расходники и постоянные апгрейды.
- Три концовки: герой, фрилансер и гусь-король.
- Сторис-сцена перед боссом: выбираешь превью, заголовок и музыку, снимаешь видео и получаешь хайп, который ослабляет финального босса.
- Финальный «видео-итог» с просмотрами, лайками и комментариями.
- Сюжетные развилки, предметы, экипировка, прокачка и выбор талантов.
- Случайные мемы в бою: стан, бафф, лечение... или кринж.
- Автосохранение, «Продолжить», финальная оценка по KPI и кнопка «Скопировать подвиг».
- Режим производительности в меню: отключает частицы, зерно и blur на слабых устройствах.
- Смерть не отменяет прогресс: бабушка всегда рядом с шаурмой.

## Файлы

- `index.html` — разметка экранов и модалок.
- `style.css` — вся вёрстка, анимации и адаптив.
- `game.js` — данные, бои, сюжет, сохранения, звук.
